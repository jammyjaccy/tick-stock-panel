3. **不猜**: 数据源能力未实测的, 票内第一步就是只读验证; 验证不通过就关票, 不硬做.
4. **可回滚**: 所有写数据的票必须能一键撤销 (删除本票新增的文件/分区), 并在票内写明回滚命令.
5. **文档同步**: 票完成后更新 data-inventory.md 对应行, 并记录验收时间.
