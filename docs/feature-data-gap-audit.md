# 功能—数据缺口清单 (以页面为基准)

实测时间: 2026-11-18 19:50-20:20, 全部为本地只读 GET, 未触发任何写操作.
方法: 页面 -> 它调用的接口 -> 直接请求接口 -> 看返回是否为空/是否为旧日期.

一句话结论: **大多数页面有数据; 真正"点进去空的"只有 5 处, 其中 2 处能补、3 处受数据源限制.**

## 二. A 类: 点进去是空的, 需要找数据

### A1. 指数分时图 (指数页)

- 现象: `/api/index/minute?symbol=000001.SH` 返回 `rows: [], source: "none"`.
- 根因: 磁盘上没有 `kline_index_minute` 目录, 指数分钟从来没同步过.
- 能补吗: 待验证. a-stock-data 的腾讯分钟K 只验证过个股, 指数分钟没测; 通达信已无积分.
- 优先级: 中. 指数分时是看盘常用, 但不影响选股/回测.

### A2. 连板梯队"封单"列 (连板梯队页 / 看板)

- 现象: `sealed_status: null`, `sealed_vol: null`; 日志明确 `五档盘口 ← TickFlow(档位不足) 不可用`.
- 根因: 五档能力当前路由到 TickFlow(none), 磁盘 `depth5/` 0 个文件.
- 能补吗: **能**. M0 已实测腾讯 quote 9-28 字段含沪深北五档, 免费; 只差实现插件.
- 优先级: 高 (你的目标之一"盘中找机会").

### A3. 分钟K 只有 4 天

- 现象: 分时图只能看 11-12 之后; 分钟回测无数据.
- 根因: 通达信积分耗尽, `minute_sync_enabled=false`; 现有 4 天是最后一批.
- 能补吗: **历史补不了**. a-stock-data 分钟K 逐只、最多 320 根 (约 1.3 天)、无成交额、北交所不支持.
- 现实选择: 要么接受"只在当天盘后补最近 1-2 天、按需逐只", 要么放弃历史分钟.

### A4. 财务指标没有历史

- 现象: `/api/financials/metrics?symbol=600519.SH` 只返回 1 期 (2026-09-30).
- 根因: 扶摇指标接口是"单股单期", 代码里固定只拉最新一期 (`provider.py:972`), 不是 bug.
- 能补吗: 三表有 8 期; 指标历史需要换源 (TickFlow 无档位 / stockdb 待验证财务表).
- 优先级: 中 (财务因子回测会受影响).

### A5. 日K 历史只有 1 年 (2025-11-17 起)

- 现象: 回测/因子/选股全部局限在 2025-11-17 之后.
- 2026-11-18 20:29 的变化: 用 600519 请求 2021-08-16~08-20 时, 面板的
  `daily_bootstrap.ensure_history` 自动回补并落盘了 2020-08-20~2021-08-19 共 245 天,
  **每天只有 600519 一行**. 因此 `/api/data/status` 的 `trading_days` 从 244 变 489,
  但这个数字只是分区数, 不代表覆盖面.
- 关键发现: 面板自身已有"按需回补"链路 (扶摇 historical-batch), 回补结果与通达信包
  逐字段一致 (600519 2021-08-16: 1699.2 / 28,056 手 / 4,773,049,794 元 全部相等).
- 能补吗: **能**, 两条路: 通达信盘后包 (已验证) 或 面板扶摇链路批量回补 (待验证批量能力).
- 优先级: 高 (直接决定回测可信度).

## 三. B 类: 有数据, 但是旧的 / 只有按需

| 功能 | 状态 | 说明 |
|---|---|---|
| 板块轮动 | 停在 2026-11-17 | 依赖全量分钟, 分钟停了它就停在最后一天; 资金流列 `flow_available: false` (没有 flow 扩展表) |
| 龙虎榜 | 今天有 | 只在有人点某一天时拉取并缓存, 历史没有预拉; 回看 10 天要点 10 次 |
| 概念 / 行业 | 今天有 | 只有"当前归属"快照, 没有历史归属; 回测板块轮动会有前视偏差 |

ETF 全空 (面板没有 ETF 页面, 不影响任何按钮).

## 五. 日K 怎么补: 可执行方案

### 5.1 现在与目标

```
现在: 2025-11-17 ~ 2026-11-18, 244 个交易日
目标: 2021-08-16 起, 约 1,030 个交易日 (4.25 年)
起点已验证: 2021-08-16 包可下载, 19,843 行 (仅沪深, 北交所当时未开市)
```

### 5.2 补完后你在页面上能看到的变化

| 页面 | 现在 | 补完后 |
|---|---|---|
| 回测 | 最早只能选 2025-11 | 可选 2021-08 起 |
| 因子 / 选股 | 4 年样本缺失, 指标暖机短 | 指标 4 年历史, 可做跨周期验证 |
| 个股日K | 244 根 | 约 1,270 根 |
| 财务因子 | 指标 1 期 | 不变 (财务指标另案) |
| 分钟 / 五档 | 不变 | 不变 (另案) |

### 5.3 三步执行

**第一步: 试写 5 天 (可回滚)**

- 取 2021-08-16 ~ 2021-08-20 五个包;
- 转单位 (股 ÷100 = 手), 写成 5 个日期分区;
- 检查: 数据页天数 244 -> 249, 原 244 天不变, 日K 页能翻到 2021-08-16, 跨边界价格连续;
- 成本: 5 次下载, 约 3 分钟, 2 MB.

**第二步: 分批补全 (约 1,030 天)**

- 每批 60 天, 失败即停, 已落盘跳过, 可断点续跑;
- 预计 2 小时, 磁盘 +约 1 GB (现有余量 1.6 T).

**第三步: 除权因子 + 指标**

- 事件日历用 stockdb (已验证), ex_factor 用包价推导 (已验证, 27/27 完全一致);
- 只对新增日期重算 enriched;
- 回测基线对比: 原 244 天窗口结果必须不变.

### 5.4 不在本次范围

北交所历史 (新旧代码映射问题, 另案), 分钟历史, 财务指标历史, 指数分时.
