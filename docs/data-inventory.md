## 3. 关键发现: 本地已有一份未被使用的 10 年历史

清点时发现扶摇 provider 会在"窗口较深"时下载全量 dump, 而这份 dump 已经躺在本地:

```
cache/fuyao/daily_k__20261116.parquet      182 MB
  行数        10,396,202
  标的         5,579 (沪 4,376,796 / 深 5,737,623 / 北 281,783 行)
  交易日       2,428 天, 2016-11-16 ~ 2026-11-16
  每日标的     最少 2,536 / 中位 4,405 / 最多 5,573
  字段         thscode, date_ms, open/high/low/close_price, volume(股), turnover(元)

cache/fuyao/adj_factors__20261118.parquet   299 KB
  行数        57,830 条除权事件, 5,438 只
  事件区间     1991-02-26 ~ 2026-11-26
  字段         dividend_per_share, per_share_bonus, allotment_ratio, allotment_price
```

抽样核对 (600519 贵州茅台):

| 日期 | dump close | dump volume | 面板/通达信包 | 判定 |
|---|---|---|---|---|
| 2021-08-16 | 1699.2 | 2,805,697 股 | 1699.2 / 28,056 手 / 47.73 亿元 | 完全一致 |
| 2020-08-20 | 1664.0 | 2,238,233 股 | 面板回补 1664.0, 22,382 手 | 一致 |
| 2025-11-17 | 1471.0 | 3,446,221 股 | 1471.0 / 34,462 手 | 一致 |

**待补区间 2021-08-16 ~ 2025-11-16: 1,029 个交易日, 平均每天 5,025 只 = 约 517 万行.**
同一区间的除权事件: **16,917 条 (4,628 只)**.

结论: 日K 历史与除权因子历史**不需要下载任何外部数据**, 只需要一个"从 cache 导入正式表
+ 重算 enriched"的迁移步骤. 之前的"下载 1,030 个通达信包"方案可以作废.

## 8. 面板现在没有、但 a-stock-data 有的能力 (值得单独评估)

这些不是"补缺口", 是"新增数据品类":

| 品类 | 对应用户目标 |
|---|---|
| 涨停池/炸板池/跌停池/昨涨停/打板情绪/异动 | 盘中找机会 |
| 板块资金流 + 个股资金流 (当日/5日/10日) | 盘中找机会 / 选股 |
| 融资融券、股东户数、增减持、回购、解禁、分红送转 | 选股因子 |
| baostock 估值历史 (PE/PB/换手/ST, 2016 起) | 选股/回测因子 |
| 业绩预告、机构调研 | 选股/事件驱动 |
| ST 名单、退市日、交易日历 | 数据质量 |
| 申万行业变迁史 | 消除行业回测的前视偏差 |

## 9. 结论

1. **日K/除权因子/指标这 3 项不需要 a-stock-data**, 本地 cache 已有 10 年数据, 缺的只是导入步骤.
2. **a-stock-data 真正能补的缺口只有 3 项**: 五档封单、板块资金流、龙虎榜历史.
3. **它补不了的**: 分钟历史、概念/行业历史、Level-2.
4. 它更大的价值在**新增能力** (涨停池/两融/估值历史/事件), 需要单独评估是否要做.
