## 十一. 明确没有的能力

- 无回测引擎 (只取数).
- 无 Level-2 逐笔委托/成交; 只有约 3 秒聚合的分笔, 仅最近一日.
- **无分钟历史回补**: 逐只、<=320 根、无成交额、无北交所.
- 无板块成分股清单 (只能查个股所属板块).
- 无十大股东/基金持仓/机构持仓明细.
- 无基金净值/基金持仓/基金列表.
- 无历史时点指数成分/权重.
- 无停复牌事件表 (只有逐日 tradestatus / is_stale 标志).
- 无统一证券代码表函数.
- 无业绩快报.
- 北交所缺口: 腾讯 K线/分钟/逐笔不支持; 新浪复权 404; baostock 估值/基本信息不支持; 东财研报老码报错.
- 已失效: mootdx 行情命令 (2026-09 起), 网易/和讯/凤凰/腾讯资金流/雪球免登录.
- 同花顺 NL 选股接口不可用 (JS 签名).
